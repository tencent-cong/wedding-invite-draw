# 婚礼邀请函抽签站 · 使用说明

快乐哥 ♥ 葱酱 · 2026.10.06 下午 3:00

## 一、这是什么

一个给朋友在线抽取婚礼邀请函的小站点：

- 每位朋友只能抽 **1 次**，抽到后编号锁定，刷新/重开页面仍是同一张
- 已被抽走的邀请函 **不会再进入抽签池**，15 张编号全局唯一
- 抽完可长按保存图片到相册，或点按钮直接下载
- 附带后台页面，可查看谁抽了哪张、还剩哪些编号

## 二、目录结构

```
site/
├── server.py          # 后端服务（Python 标准库，零依赖）
├── public/
│   ├── index.html     # 抽签页（朋友访问的页面）
│   └── admin.html     # 后台记录页
├── invites/           # 15 张邀请函图片，文件名即编号
│   ├── 1317.jpg
│   └── ...
└── data/
    └── claims.json    # 抽签记录（谁抽了哪张，自动生成）
```

## 三、本地启动

```bash
cd site
python3 server.py
```

打开 `http://127.0.0.1:52368` 即可。

自定义端口和后台密钥：

```bash
PORT=8080 ADMIN_KEY=你的密钥 python3 server.py
```

后台地址：`http://127.0.0.1:52368/admin`，默认密钥 `congjiang`。

## 四、让朋友能访问（三种方式）

### 方式 1：内网穿透（最快，适合当天临时用）

```bash
npx localtunnel --port 52368
# 或
ssh -R 80:localhost:52368 nokey@localhost.run
```

拿到的公网地址发到群里即可。缺点是你电脑需保持开机联网。

### 方式 2：部署到云服务器（推荐，稳定）

把 `site/` 整个目录上传到任意一台有公网 IP 的服务器，然后：

```bash
nohup python3 server.py > run.log 2>&1 &
```

建议用 Nginx 反代并配 HTTPS（微信内打开 http 站点会提示不安全）。

### 方式 3：部署到 Serverless / 容器平台

`server.py` 是标准 HTTP 服务，可直接放进腾讯云 Serverless、Cloud Run、Railway 等平台，
注意把 `data/` 挂到持久化存储上，否则实例重启会丢失抽签记录。

## 五、常见调整

**加/换邀请函**：往 `invites/` 里丢新图片，文件名用编号命名（如 `4821.jpg`），
服务会自动识别，无需重启改代码。

**重置抽签**（比如测试完想清空）：

```bash
echo '{"claims": {}}' > data/claims.json
```

**给某人补一张**：让 ta 换个浏览器/清掉该站点的浏览器数据（localStorage）再抽即可。

**防同一人换设备重复抽**：当前用浏览器标识记账，够应付亲友场景。
若要更严格，可改成"新人预先给每位朋友发一个专属邀请口令，凭口令抽签"，
这样一人一码，换设备也无法多抽。需要的话告诉我，我给你加上。

## 六、注意事项

- `data/claims.json` 是唯一的抽签账本，换机器部署记得一起带走
- 微信里打开建议用 HTTPS 域名，否则可能被拦提示
- 图片已压缩到约 250KB/张，手机流量下加载很快
